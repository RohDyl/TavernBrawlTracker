⚡ Setup

Table: about 36" × 30". 30–36" deep plays well; avoid deeper than 36".
Each player takes an edge. Deploy within 6" of your edge (your deployment zone).
Place 3 Prize Tokens on the centre line — 6" apart, and 6" from each deployment zone (12" from each edge).
Shuffle Gear deck. Each player draws an opening hand of 5 cards.
Both roll d20. Highest wins Turn 1 initiative. Reroll ties.
Alternate placing models. Initiative player places first.
🍺 The table is the terrain. All objects = Clutter (Scavenge) and Cover (+4 Def).

🧠 Core Concepts

👊 Engaged

Within 1" of an enemy, base edge to base edge. All distances work the same way. You must be engaged to Fist Fight.

👁 Line of Sight

Straight line attacker → target. Blocked by models & terrain taller than the model.

🛡 Cover

Within 1" of Clutter between you and the attacker. +4 Defence. Fist Fights and ranged. Same object can be Scavenged.

🔄 Turn Structure — 4 turns or until one squad is fully KO'd

1 — Order Phase
Clear spent Order Tokens beside models.
Gain 1 Order Token per model (Brutes: 2). Each model spends only its own — a Brute up to two.
Place a Command Token beside your BB (if alive). Separate from Order Tokens.
Draw 1 Gear card per model on the table. Deck out → reshuffle discard.
Bid initiative (T2+): each player may bid 1 card or nothing. Tips rank 10c < 20c < 50c < R1 < R2. Highest wins; one bid wins. No bids = holder keeps. Tie = whoever didn't have it last turn. Discard the bids.
2 — Action Phase
Initiative player chooses who activates first, then alternate.
1 Order Token = one activation. Place the spent token beside the model. A Brute may be picked twice.
Sequence: choose option → move → Action. One buff/Free during the move or Action. Then Scavenge if touching Clutter.
Command Token: spending it is your slot in the alternation, even if you still have Order Tokens. Any friendly model, even one already activated (1 Command Token per model unless the Colonel). Lost if BB KO'd. No activation cap.
Pass when out of tokens or by choice. Phase ends when both pass.
3 — End Phase
1. Unengaged model within 1" claims a Prize: +3 pts. One model may claim more than one. All claims at once. Contested (both sides have an unengaged model within 1") = nobody claims it.
2. Turn 4 ends the game — score it. A wipe-out wins immediately at any time.
3. Discard down to 7 cards.

⚔️ Actions

⚡ You always MOVE (up to Speed) + take ONE Action + may play ONE buff/Free. The move and the action are separate — you can move AND act.
⚔️ Move & Act (default)
Move up to Speed, then Fist Fight an engaged enemy OR play 1 Order card (ranged, heal, etc.).
⚠️ Provokes Retaliation when moving while engaged.
🥊 Stand Your Ground
No movement → Fist Fight. Scrapper: +1 attack die. Brute: +1 defence die until that Brute's next activation starts.
💨 Leg It
Move up to Speed twice (any directions). No Action — you may still play a buff and Desperate Acts.
⚠️ Provokes Retaliation on each move that leaves 1".
🚶 Shove Through
Move up to Speed in a straight line. Path can't cross a model or terrain taller than 1". No Action — this is the whole activation.
✦ No Retaliation, even if you started engaged.
🎴 Scavenge — Free Action
Each model once per turn, if touching Clutter: draw 2 cards, keep 1. Does NOT use your Action.

🥊 Combat

Every die: exactly the value = CRIT · natural 1 = auto-fail — on both attack & defence.
① Attack (must be engaged)

≤ Skill = Hit (1 dmg)

= Skill = CRIT (2 dmg, needs Crit Block)

Nat 1 = miss

② Defence

Roll 1 die per landed attack die + any bonus dice.

≤ Def = Block (stops 1 Hit)

= Def = CRIT BLOCK (stops 2 / cancels a Crit)

Nat 1 = fail

③ Resolve

Crit Block cancels a Crit (or 2 Hits). Normal Block can't touch a Crit. Net dmg = total unblocked.

🎯 Example

Brute rolls 14,9,1 → Crit + Hit. Scrapper (Def 10) rolls 2 dice: 10,6 → Crit Block + Block = 0 dmg!

👥 Gang Up

Scrappers +1 atk die per friendly Scrapper within 4" (max +2). Primary Fist Fight only — not free/reaction FFs.

⚔️ Retaliation

Start within 1" and the move leaves 1", or a ranged card while engaged → each engaged enemy free-Fist-Fights first. Provoker KO'd = action cancelled. No Gang Up. No chaining.

Defensive Reactions (Pocket Sand, Trash Can Lid, Dig In, Whoops!) after the attack roll, before defence dice. Defender picks the Pocket Sand die. Ranged cards roll only the dice printed. Can't shoot who you're engaged with. Shooting elsewhere provokes Retaliation.

🩸 Blood & Bloodied

Losing vs Spending

Losing — from attacks/cards.

Spending — using a Desperate Act.

Both reduce count. At 0 → KO'd, removed.

🔥 Bloodied = Unlock

Scrapper ≤2 · Brute ≤3 · BB half or below (flip card).

When Bloodied: DAs use enhanced version & you may do 2 DAs per activation.
